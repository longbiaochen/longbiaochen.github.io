Pattern Recognition


Course Overview

Pattern recognition studies how computational methods can identify, classify, and interpret patterns in data. Designed for second- and third-year undergraduates, this course introduces the core concepts, terminology, workflow, methods, history, and current development of pattern recognition. It progresses from classical pattern recognition to deep learning and concludes with foundation models and large language models. Hands-on tutorials connect the underlying principles to practical machine-learning projects and prepare students for further study and research in artificial intelligence.

Course Project: An LLM-Powered AI Course Assistant

Goal

  • Develop an intelligent course assistant that analyzes video content in real time and provides personalized explanations and question answering.
  • The system should include a course-video player and an “I don't understand” action that analyzes the current segment, explains it, and supports follow-up dialogue.

Module Tracks

  • Track A — Front-end interaction: video player and timeline synchronization, dynamic triggering of the “I don't understand” action, and visualization of analysis results
  • Track B — Back-end services: video metadata management, contextual-segment extraction APIs, and result caching
  • Track C — Model processing: video summarization, contextual analysis of questions, and multimodal response generation
  • Track D — Data engineering: course-video segmentation, knowledge-graph construction, and learning-behavior log analysis
  • Track E — Extended features: voice questions, screenshot-based question answering, and learning-progress analytics

PRD Requirements

  • Background and objective: locate the module within the system architecture and define the problem it addresses
  • Requirements analysis: specify functional requirements and proposed strategies
  • Technical design: describe the core technical approach and implementation path
  • Innovation: present original ideas and explain their value
  • Demo: include a concrete demonstration, such as interface mock-ups or screenshots, to make the proposal feasible and understandable
