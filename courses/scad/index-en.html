Software Architecture and Application Development


Course Overview

Large student projects often become difficult to maintain: hundreds of source files, defects that are hard to trace, and painful merges of independently developed code. This course helps third- and fourth-year undergraduates address those problems through two connected themes: software-architecture principles and styles, and the use of design patterns in application development. Students learn the foundations of software design and apply them in a complete team project.


Course Objective

Students form teams of one to four and select a software project, such as a library-management system, mobile game, blockchain application, or face-recognition system. Each team designs the system with modern software-architecture principles and design patterns, implements and tests it, and delivers project documentation and a presentation. The programming language, platform, and presentation format are open choices.


Project Platform

  • XMU-SCAD on Gitee Education
  • Team formation, proposals, project management, reviews, and in-class quizzes are managed on Gitee.
  • Contributions and pull requests are welcome.


Assessment

  • Final project (50%), including:
    • Documentation prepared according to GB/T 8567-2006, Specification for Computer Software Documentation, using the provided [Word template]
    • Source code following an applicable Google Style Guide
    • Presentation using the provided [slide template]
  • Coursework (50%): attendance, in-class quizzes, and related work

Instructor

Longbiao Chen is an Associate Professor and Doctoral Supervisor in the Department of Computer Science, School of Informatics, Xiamen University. His research focuses on crowd intelligence, embodied intelligence, spatial computing, ubiquitous computing, and domain-specific large language models. He teaches software engineering and pattern recognition and mentors student research, innovation, and entrepreneurship projects.
