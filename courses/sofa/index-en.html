Software Engineering


Course Overview

This four-credit course is designed for fourth-year undergraduates. It integrates the foundations of software engineering with development practice and project-management methods. Students learn the principles of sound software design and apply them throughout a complete, team-based project.


Learning Outcomes

  • Understand the processes, criteria, standards, specifications, and feasibility-analysis techniques used in software development.
  • Apply theories, methods, techniques, standards, tools, and environments for software development and maintenance.
  • Understand the software-project lifecycle and strengthen practical software-engineering capability.


Assessment

  • Laboratory work (15%): practical assessments using Visio, Project, and PowerDesigner, each worth 5%
  • Team project (35%): delivery of a complete software-engineering project, including:
    • Presentation (10%): slides, video, and/or live demo using the provided slide template
    • Documentation (15%): SRS, SDD, SUM, and related artifacts using the GB/T 8567-2006 software-documentation templates
    • Source code (10%): repository, commits, and release artifacts following an applicable Google Style Guide
  • Final examination (50%): closed-book written examination


Course Project

  • Format: teams of three to five develop and test an application, such as a face-recognition system, and deliver the source code, software documentation, and presentation. The programming language, platform, and presentation format are open choices.
  • Management: team formation, proposals, development, and reviews are hosted on Gitee; see the Gitee guide.
