前言

​学弟在此班门弄斧了，如果您之前没接触过Vue.js或者React等前端框架，那么今天听完我的讲述后能够对Vue.js有一个感性的认识。不过我相信在座的各位应该都是开发经验丰富的大牛，希望能够受到各位学长学姐的批评指正。

1. 快速开始

  • Vue.js官网 
https://cn.vuejs.org/

安装

1. 直接用< script >标签引入（新手推荐，感受一下Vue.js）

  1. 下到本地
  2. CDN（Content Delivery Network，即内容分发网络）方式 <script src="https://cdn.jsdelivr.net/npm/vue/dist/vue.js"></script>

我觉得的Vue的三种主要特性

  • 内容是可以插值的
  • 属性是可以绑定的
  • 组件是可以复用的

2. 上Vue CLI

安装npm，以ubuntu18.04为例

sudo apt-get install nodejs

此时使用命令

npm -v

检查一下npm是否正常安装

中国大陆用户用国内镜像cnpm比较快

[sudo] npm install -g cnpm --registry=https://registry.npm.taobao.org

安装 vue-cli

[sudo] cnpm install -g @vue/cli

检查一下是否安装成功

vue --version

创建一个vue项目，名为vue-demo

vue create vue-demo

接着回车选择default即可

2. 学Vue当然离不开组件

2.1尝试自己造个轮子

2.2 尝试安装一个组件吧——以百度地图组件为例

npm install vue-baidu-map --save
引入组件
  • 全局引用
  • 局部引用

此处有一坑！（如果你不熟悉前端开发的话）
